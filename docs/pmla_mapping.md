# PMLA Mapping

This document maps the structural fraud patterns detected by the Sampati engine to the stages of money laundering defined by the Prevention of Money Laundering Act (PMLA).

## Fraud Patterns to PMLA Stages

| Sampati Fraud Pattern | PMLA Stage | Description |
|----------------------|------------|-------------|
| FAN_OUT | Placement | Dispersing large illicit sums into multiple smaller accounts to avoid reporting thresholds. |
| FAN_IN | Integration | Collecting dispersed funds into a single mule collector account to re-enter the legitimate economy. |
| SCATTER_GATHER | Layering | Multi-hop splitting and converging of funds to obfuscate the origin of money (Smurfing). |
| MULE_CHAIN | Layering | Rapid linear transfer of funds across multiple mule accounts to create distance from the origin. |
| VELOCITY_ABUSE | Placement / Layering | High-speed automated transfers indicative of bot networks moving illicit funds. |
| ROUND_TRIP | Layering | Funds returning to the originator through intermediaries to create false transaction history. |

## FIU-IND STR Field Mapping

The structured JSON alerts generated by the `pattern_detector` directly map to the fields required by the Financial Intelligence Unit - India (FIU-IND) for Suspicious Transaction Reports (STRs).

| Sampati Alert Field | FIU-IND STR Field |
|--------------------|-------------------|
| `alert_id` | Internal Reference Number |
| `implicated_accounts` | Suspect Account Numbers (Section 3) |
| `implicated_transactions` | Suspicious Transaction References |
| `explanation_text` | Ground of Suspicion (Section 5) |
| `risk_score` | Risk Category |
